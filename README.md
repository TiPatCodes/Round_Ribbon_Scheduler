This project is about developing a round robbin scheduler from scratch on a STM32F407 MCU using assembly level instructions.

A assembly level coding is a key skill required in embedded development with the Baremetal programming.

There are four tasks being executed by a scheduler, which interrupts the processor every 1 ms.

For a interrupt noisy evnvironment - it's absolutely must to have a context switching using a PendSV exception.
